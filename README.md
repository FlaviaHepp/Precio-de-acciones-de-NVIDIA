# Precio-de-acciones-de-NVIDIA
Análisis y visualización de precios de acciones de NVIDIA.

**Desarrollo:** 
Implementación de un sistema de análisis y predicción de precios de acciones para NVIDIA utilizando datos históricos (2015-2024). Incluye el análisis de patrones históricos, el cálculo de indicadores financieros, y la predicción del precio de cierre ajustado.
*Tecnologías Utilizadas:* Python, pandas, NumPy, scikit-learn, CatBoost, TensorFlow (LSTM), matplotlib, seaborn y plotly.
**Métodos Aplicados:**
Análisis exploratorio de datos (EDA) para identificar tendencias de precios, patrones de volumen y retornos diarios.
Uso de promedios móviles (MA50 y MA200) para destacar tendencias de mercado.
Modelado predictivo mediante regresión lineal, árboles de decisión, bosques aleatorios y CatBoost.
Evaluación de modelos con métricas como MAE, MSE y R².
Visualización interactiva de datos utilizando Plotly para el análisis de precios y volúmenes.

**Resultados:**
Modelo CatBoost alcanzó un R² de >90% en la predicción del precio de cierre ajustado.
Generación de insights accionables sobre la relación entre volumen de operaciones y variaciones de precios.
Mejora de la comprensión de las dinámicas del mercado financiero a través de análisis basados en datos.
